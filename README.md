This project focuses on predicting customer churn using machine learning techniques. The dataset is sourced from Kaggle and includes customer demographic and behavioral information. The workflow involves data
preprocessing, exploratory data analysis (EDA) with visualization, and model training using a Random Forest Classifier.

The primary objective is to identify customers who are likely to leave a service, enabling businesses to take proactive retention measures.


🎯 Objectives
1)Perform data cleaning and preprocessing on raw dataset
2)Conduct exploratory data analysis (EDA) with visual insights
3)Encode categorical variables for machine learning compatibility
4)Build a predictive model using Random Forest Classifier
5)Evaluate model performance using standard metrics

🛠️ Technologies Used
Python 🐍
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn

🔍 Data Preprocessing

The following preprocessing steps were applied:

Handling missing values
Encoding categorical variables using Label Encoding
Converting object data types into numerical format
Feature selection and separation of input/output variables
Train-test data splitting


🤖 Model Development
Algorithm Used:
Random Forest Classifier 🌲
Workflow:
Splitting dataset into training and testing sets
Training Random Forest model on training data
Predicting outcomes on test data
Optimizing model performance

📈 Model Evaluation

The model performance was evaluated using:

Accuracy Score
Confusion Matrix
Classification Report (Precision, Recall, F1-score)
